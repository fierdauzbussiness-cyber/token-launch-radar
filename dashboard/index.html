TOKEN RADAR

Pre-token protocols, ranked by what their token would be worth if the record stood as it is.

How the radar scores

implied value = TVL × category multiple × growth × maturity × chains

The category multiple is the live market's own price for that kind of protocol: the median market-cap-per-TVL of the snapshot's already-trading protocols in the same category. Growth is the 7-day TVL change, clamped to −50…+100%. Maturity rewards how long a protocol has run with no token recorded. Chains adds a small premium for multichain reach. No name is ever special-cased: one function scores every row.

Category multiples used (live comparables from this snapshot)

A protocol is listed as records no token when the snapshot carries no market cap, CoinGecko id or symbol for it — the record is not proof it has none. Implied value is this entry's own claim, never a prediction that a token will be issued, or when.
